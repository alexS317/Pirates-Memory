## About The Project

![Pirates Memory Game][product-screenshot-1]

I built this project as a final project for my 3rd semester university course "Advanced Topics of JavaScript". The assignment was to build a small browser game or simple website using Vue/Nuxt. I decided to create a memory game and theme it after one of my favourite movie series.

## Getting Started

Here you find the instructions on how to set up the project locally.

### Prerequisites

Make sure you have the following installed:

- [node.js](https://nodejs.org/en/download) (v22 or later, LTS is recommended)

### Installation

1. Clone the repo (or download the project as a zip file)
   ```sh
   git clone https://github.com/alexS317/Pirates-Memory.git
   cd Pirates-Memory
   ```
2. Install NPM packages
   ```sh
   npm install
   ```
3. Start the development server
   ```sh
   npm run dev
   ```
4. Open your browser at [http://localhost:3000/](http://localhost:3000/)
